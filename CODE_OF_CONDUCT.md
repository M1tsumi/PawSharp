# Code of Conduct

As contributors and maintainers of PawSharp, we pledge to foster a welcoming and respectful community for all.

## Our Standards

- Be respectful and considerate in all interactions.
- Do not use discriminatory, harassing, or offensive language or behavior.
- Accept constructive criticism gracefully.
- Help create a collaborative, inclusive environment.

## Enforcement

Violations of this code may result in removal from the project community. If you experience or witness unacceptable behavior, please report it to the maintainers.

---

Thank you for helping make PawSharp a friendly and productive place for all developers.
